# Task 2 – RA-4 Robotic Arm Simulation

| Folder / file | Content |
|---------------|---------|
| `CodeAlpha_Task2_RA4_Arm_Simulation.pdf` | Report: design, degrees of freedom, pick-and-place simulation |
| `CAD/RA4_Arm_Mustafa_Ali_Mohsin_Albusultan.f3z` | Autodesk Fusion archive with joints, joint limits, motion links and motion study |
| `CAD/RA4_Arm_Mustafa_Ali_Mohsin_Albusultan.step` | STEP geometry for other CAD programs (no joints or motion) |
| `Screenshots/` | Home pose, joint axes, and the pick, transfer and place poses |
| `Video/RA4_motion_study.mp4` | 39 s video: each DOF demonstrated separately, then the pick-and-place cycle with live joint angles |

**How to view the simulation:** open the `.f3z` file in Autodesk Fusion (File → Open → Open from my computer), go to the Assemble menu,
then Motion Study, and press Play.

**Degrees of freedom:** 4 revolute joints (base, shoulder, elbow, wrist pitch) plus a rack-and-pinion gripper.
